## Pasos realizados

1. Inicializar entorno e instalar @angular/cli

```bash
npm init -y
npm i @angular/cli
```

2. Inicializar el proyecto

```bash
 npx ng new mini-aplicacion
```

3. Generar los 3 componentes que nos hacen falta
```bash
npx ng g c home
npx ng g c login
npx ng g c about
```


4. Generar el componente de menu
```bash
npx ng g c layout/menu
```
